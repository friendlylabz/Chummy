# Using Chummy

1. [Getting started](getting-started.md): install Chummy, connect a model,
   set up your first agent, and find your way around a chat.
2. [Loops and the loop editor](loop-editor.md): what a loop is, how the
   editor works, and how to build loops that small models get right.
3. [Settings](settings.md): every settings page, what it changes, and the
   safe defaults.

Chummy assumes the model behind it may be small and easily confused. So
every agent is locked to one folder you choose, tools and internet access
are off until you turn them on, and everything about how an agent thinks
can be seen and changed in the app.
